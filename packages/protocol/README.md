# @invisi-labs/protocol

Pure public protocol contracts: ABIs, public DTOs, strict codecs, public inputs, signature digests, capacities, deployment validation and receipt-calibrated local gas estimates. Depends on primitives; contains no network calls or proving runtime.

Install with `npm install @invisi-labs/protocol@1.2.4`. API documentation and runnable examples are in the [SDK repository](https://github.com/invisi-lab/invisi-sdk-ts).
