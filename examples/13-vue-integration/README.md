# 13 - Vue Integration

Vue 3 + Vite frontend integration example demonstrating how to use the `usePayOpen` composable to build payment calldata in a Vue application.

## Packages Used

- `@invisi-labs/vue` -- Vue composables (usePayOpen)
- `@invisi-labs/payer` -- Payment calldata construction

## Running

```bash
bash run.sh
```

Visit http://localhost:5173

## Prerequisites

- Node.js 20+
- pnpm 9+
