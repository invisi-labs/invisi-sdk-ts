# 11 - Proof Generation

Server-side ZK proof generation example demonstrating how to use the `@invisi/node` package to generate Noir ZK proofs. Suitable for server environments with compute resources.

## Packages Used

- `@invisi/node` -- ZK proof generation (checkBBAvailable, generateProof)

## Running

```bash
bash run.sh
```

## Prerequisites

- Install nargo (Noir compiler)
- Install bb (Barretenberg prover)
- Installation guide: https://noir-lang.org/docs/getting_started
