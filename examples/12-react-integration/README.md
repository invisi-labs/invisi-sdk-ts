# 12 - React Integration

React + Vite frontend integration example demonstrating how to use the `usePayOpen` hook to build payment calldata in a React application.

## Packages Used

- `@invisi/react` -- React hooks (usePayOpen)
- `@invisi/payer` -- Payment calldata construction

## Running

```bash
bash run.sh
```

Visit http://localhost:5173

## Prerequisites

- Node.js 20+
- pnpm 9+
