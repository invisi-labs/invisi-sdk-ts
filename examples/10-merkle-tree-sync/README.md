# 10 - Merkle Tree Sync

Merkle Tree sync example demonstrating how to sync on-chain Merkle Tree state and obtain Merkle proofs. Used in scenarios that require tree proofs, such as blind payments and withdrawals.

## Packages Used

- `@invisi/tree` -- InvisiTreeManager
- `@invisi/deployments` -- Contract addresses

## Running

```bash
bash run.sh
```

## Prerequisites

- Configure `.env` (RPC_URL, optional)
- RPC connection to Base Sepolia
